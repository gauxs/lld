# Problem template

Copy [`problem/`](problem/) into `problems/<problem_name>/` when starting a new LLD problem.

| Path | Use |
| --- | --- |
| [`CONVENTIONS.md`](CONVENTIONS.md) | Extension naming, `buildsOn`, markdown patterns |
| [`problem/extensions.json`](problem/extensions.json) | Sidebar order and extension metadata |
| [`problem/extensions/baseline/requirements.md`](problem/extensions/baseline/requirements.md) | FR/NFR template with site CSS hooks |
| [`problem/extensions/baseline/design.md`](problem/extensions/baseline/design.md) | Entity and API tables |

Full site workflow (sync script, VitePress, registering a new problem): **[setup.md](../setup.md)** at the repo root.
